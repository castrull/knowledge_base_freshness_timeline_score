# vecdb_jd142

**按时间线排列向量数据库内核工程师·知识库的时效性维护并标出节奏异常。**

`vecdb_jd142` —— 解析时间标记，排列向量数据库内核工程师·知识库的时效性维护的发生顺序，标出间隔异常与逆序事件

- 零依赖，Python 3.10+ 标准库即可运行
- 单文件，`vecdb_jd142.py` 拷走就能用
- 不联网、不写文件

- 目标岗位：**网易 · 资深向量数据库内核工程师**
- 技能主线：向量数据库、C++、SQL
- 领域标签：搜索推荐广告、数据平台
- 研究方向：向量数据库内核工程师·知识库的时效性维护

工具里的规则表就是照着上面这条岗位要求建的——每条规则都挂在技能线或领域标签上，命中时能指回具体要求。

## 安装

零依赖，Python 3.10+ 即可：

```bash
pip install castrull-vecdb_jd142
```

装完直接用命令名调用：

```bash
vecdb_jd142 --help
```

也可以不用安装，直接把 `vecdb_jd142.py` 拷走用——它只依赖标准库。

## 为什么需要它

只认能解析的时间标记，解析不了的段落单独列出而不是静默跳过

它遵守下面几条自己定的规矩：

1. **只报告能定位到具体位置的结论**，不做语义猜测。
2. **规则表公开**，每条命中都能对应到岗位要求的一条明示规则。
3. **输入为空或格式不对时明确报错**，不静默返回空结果。

## 用法

```bash
python vecdb_jd142.py --file input.txt
python vecdb_jd142.py --text "示例内容"
python vecdb_jd142.py --file input.txt --json
```

加 `--json` 可以拿到机器可读的结果，便于接到流水线里。
